# Destinos

`output/` está montado como `/files/output` para artefactos locales de n8n.

Los borradores LinkedIn se guardan en Google Docs. Define `GOOGLE_DOCS_FOLDER_ID` si quieres organizarlos en una carpeta concreta de Drive; vacío usa la raíz del Drive de la cuenta OAuth.

Las notificaciones se realizan con WhatsApp Cloud API y toman sus datos exclusivamente desde `.env`.
